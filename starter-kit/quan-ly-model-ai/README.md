## Mô tả 
Hệ thống **quản lý model** *trí tuệ nhân tạo* chạy tại ```web/index.html```

|Thư mục|nội dung|

|docs|Tài liệu bàn giao|
|data|Bảng tính quản lý model|
|logs|Log vận hành model AI|

```shell
Get-ChildItem -Recurse -Force
```
